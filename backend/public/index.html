◷
Daily reminder scheduler

EventBridge Scheduler invokes cashflow-sentinel-reminders once per day. The Lambda checks CashFlowPayments, sends upcoming reminders from the configured start window (default 7 days before due), and sends weekly overdue reminders. Fully paid invoices are skipped.

Schedule state is managed in AWS; this page does not independently query EventBridge.
